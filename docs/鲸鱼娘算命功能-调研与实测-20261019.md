# 鲸鱼娘「算命」功能：开源库调研 + 落地实测

> 2026-10-19 · 版本 v1（八字 / 起卦 / 黄历）
> 环境：Windows 10 · Python 3.12（`deepseekgirl\.venv`）· DeepSeek `deepseek-chat`

## 一、先说结论

**没有「训练好的算命模型」这回事。** 把 GitHub 和 B 站翻了一遍，凡是能用的算命项目，结构都是同一套：

```
出生时间 ──[确定性排盘引擎]──> 四柱/星盘/卦象（可核对的事实）
                                    │
                         [规则库/古籍切片] ──> 断语与依据
                                    │
                              [大模型] ──> 用人话（和人设）说出来
```

反过来做——直接让大模型「算一下我的八字」——必错：它会编节气、编日柱、把大运排反。
所以这次的做法是：**盘面 100% 本地算，断语 100% 走规则，模型只负责组织语言。**

## 四、「算命」到底怎么算（这次落地的子平流程）

1. **排盘**：公历/农历 + 时辰 → 四柱（年/月/日/时）→ 十神、藏干、纳音、地势、旬空、胎元/命宫/身宫。
2. **定强弱**：同党（比劫+印）vs 异党（食伤+财+官杀），再看得令（月令生扶）、得地（地支通根）。
   本版是**简化模型**，输出「偏强/中和/偏弱」与分数，不冒充某派精算。
3. **取格局**：以月令本气十神定格（正官/七杀/正财/偏财/食神/伤官/正印/偏印/建禄/月刃）。
4. **取喜用**：弱则喜印比、强则喜食伤财官；冬月加火、夏月加水做调候。
5. **断事**：性格（日主五行 + 强弱 + 最旺十神）、六亲缺位（无财/无官/无印/无食伤/无比劫）、
   事业（十神组合）、财运（身财两停与否）、婚恋（夫妻宫十神 + 冲刑 + 桃花）、健康（五行偏枯）、
   神煞（天乙/文昌/驿马/华盖/羊刃/禄/红鸾/空亡）、大运与流年（干支五行是否落在喜忌）。
6. **化解与建议**：只给「可执行的小事」，不给符咒、不给日期、不承诺改运。
7. **边界**：不碰生死、疾病诊断、投资、法律；结尾必须带一句「仅供参考」。

## 七、踩到的坑

1. `Solar.fromYmd()` 只有 3 个参数，传时分秒 TypeError。
2. 五行力量里藏干是**天干**，误用 `ZHI_WUXING[藏干]` 直接 KeyError。
3. 农历输入时用输入值当公历展示，日期会错一个月。
4. 黄历「宜」常是入殓/破土/安葬，群聊展示必须过滤。
5. 模型会自己把「寅戌」说成三合火局——提示词要明确「合冲以盘面为准」。
6. 意图解析没命中时，完整生辰会掉进主 AI 流程胡说，需要「完整生辰可直接认」兜底。
7. **真实群首测漏触发（2026-10-19 09:27）**：群友发「算个命」，触发词是「包含」判定，
   `算个命` 不含 `算命` 子串 → 掉进普通 AI，回了「本鲸鱼娘不是算命的」。
   已改为正则（`算[个一]?下?命` 等）+ `RE_SOFT` 兜底 + 否定词拦截。
8. 只报日期、缺时辰和性别时，原先用默认值（午时/女命）硬排，大运顺逆会错。
   已改为「先追问、并记住已报的日期」，下一条只回「女 晚上8点」也能合并后再排。
9. **追问被参与概率吞掉（2026-10-19 09:43）**：Bot 问了「报个生辰」，用户回
   `1999年7月1日 17.00，男`（没 @）→ 本地 jevos 服务（8017）挂了 → 退回 0.35 概率抽样
   → 被判「不参与」，静默丢弃，日志里只剩一条 `jevos 判定失败`。
   已加 `_divination_interested()`：本群有挂起中的算命提问时，参与判定与连续回复护栏一律放行。
10. 时间写成 `17.00`（点号）时原正则只认冒号，时辰被丢掉。已扩成 `[:：.．]`。
11. **排查顺序**：`logs/chatbot.log` 搜 `[群聊]`（收没收到）→ 搜 `[算命]`（进没进路径）
    → 搜 `jevos 判定失败`（参与判定是否降级成概率）。
12. **公历年 ≠ 命理年**：流年/大运按 `datetime.now().year` 取，立春（2 月 3—5 日）前会把年份
    和大运提前半个月切换。已加 `bazi.liunian_year()` 立春校正，并在提示词里显式写「今天」日期。
