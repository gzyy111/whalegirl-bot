## 几篇文档里最值钱的结论（省得你翻）

- **人格与行为**：模型更容易遵守「该做什么」而不是「不该做什么」，所以把「严禁复读」改写成
  正向的行为要求；输出护栏要做成机械层，不能指望 prompt 自律。
- **真唱**：`auto_shift` 默认开启会整体平移旋律，同调必须关；伴奏必须跟人声一起移调；
  子进程 cwd 不同，产物路径必须绝对。
- **算命**：触发词用「包含」判定会漏掉 `算个命`，必须上正则；算命是「bot 先问、用户再答」
  的多轮流程，答的那句通常不带 @，必须绕过参与概率抽样。
- **发送链路**：`SendInput` 打的是前台窗口；发完必须回读数据库；语音 `create_time`
  比点发送早 2—6 秒。
