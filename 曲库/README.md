# 曲库

本仓库**不附带原曲音频**（版权音频，体积也大）。目录里只保留：

- `别名.json` —— 梗歌/同音名的别名表，格式：

  ```json
  {"兰亭鸡序": ["兰亭坤序", "坤亭序", "鸡你太美"]}
  ```

  左侧是曲库里的**文件名（不含扩展名）**，右侧是群友可能说的叫法。
  梗歌一名多叫时必须配，否则点不到。

## 怎么补歌

1. 把原曲转成 **44.1 kHz WAV** 丢进本目录，文件名用「歌手 - 歌名.wav」；
2. 有别名就写进 `别名.json`；
3. **重启机器人**（曲库在启动时扫进内存，热加不生效）。

`cover_service` 会按文件名建索引，点歌时先拿整句原文撞歌名，撞不上再清理单字填充词
（「后来」不能被剥成「后」——这是踩过的坑）。
